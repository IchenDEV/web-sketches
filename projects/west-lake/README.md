# 杭州小景 · 湖山入画

以西湖水墨画为参考的交互式三维湖景。亭桥、柳树主干、岸石、石塔与乌篷船使用三维模型；远山使用绘制背景，柳冠采用绘制贴图，湖岸植被使用三维叶片。水波和柳枝缓慢运动。

## 景点

底部「西湖三十景」打开完整景目，也可用景点菜单和左右箭头逐景游览。每景可通过独立链接分享。

采用南宋旧十景、1985 年新十景及 2007 年三评西湖十景的名单。[名单来源：新华社报道](https://news.cctv.com/china/20071028/100288.shtml)。三维场景是景点特征的水墨艺术复刻，建筑与地形经过构图调整，并非测绘模型。

模型按需载入，保留最近三景；较早的模型会释放，重访时重新载入。暂停同时控制水波、树叶、飘雪、桂雨、云雾、雨线和江潮。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 生成 `dist/`，可用 `npm run preview` 预览。

## 操作

- 拖动：在限定范围内环顾。
- 滚轮／双指缩放：调整远近。
- 暂停光阴：暂停或恢复水波和柳枝。
- 归于画境：恢复初始构图。
- 留一帧：保存不含按钮的 PNG 画面。
- 全屏：切换全屏欣赏。
- H：隐藏或显示界面。

场景尊重系统的减少动态效果设置。宽屏更适合欣赏完整构图。

## 文件

`catalog.js` 管理三十景名单与画境，`atlas.js` 为景目导航，`destinations.js` 管理按需载入与材质，`atmosphere.js` 为季节动态。`main.js` 为场景与交互，`style.css` 为界面样式，`public/assets/` 包含本地模型及贴图。素材制作信息见 `ASSETS.md`。

运行中的本地服务可用 `npm test` 检查；该命令需要已安装的 `agent-browser`，可通过 `SCENE_URL` 指定其他地址。

完整三十景的切换、缓存释放、深链接和景目对话框检查：

```sh
SCENE_URL=http://127.0.0.1:5182/ node tests/thirty-scenes.mjs
```

新增 26 景的建模源码位于 `scripts/models/`，可在 Blender 中运行 `classic.py`、`new.py`、`third.py` 重建对应 GLB。
