# 杭州小景 · 湖山入画

以西湖水墨画为参考的交互式湖山画卷。三潭印月保留原来的混合三维场景：亭桥、岸石、石塔与船使用模型，柳冠与远山使用绘画贴图，湖面实时反射并产生水波。

其余二十九景采用半 3D 绘景：每景独立生成水墨原画、补全被前景遮挡的远景，再提取前景轮廓。原画笔触铺在不同深度的曲面上，左右移步时产生视差。镜头在有限范围内平移和缩放，手机可横向探索画卷。

## 景点

底部「西湖三十景」打开完整景目，也可用景点菜单和左右箭头逐景游览。每景可通过独立链接分享。

采用南宋旧十景、1985 年新十景及 2007 年三评西湖十景的名单。[名单来源：新华社报道](https://news.cctv.com/china/20071028/100288.shtml)。场景是景点特征的水墨艺术复刻，并非测绘模型。

所有景点按需载入，首屏只请求当前景点的素材。绘景使用无损 WebP；三潭印月的代码、模型和贴图在选中时下载。切换时取消旧请求；保留最近三景，淘汰时释放几何、材质、绘景纹理和图像解码内存。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 生成 `dist/`，可用 `npm run preview` 预览。

## 操作

- 拖动：半 3D 绘景左右移步；三潭印月限定范围环顾。
- 滚轮／双指缩放：调整远近。
- 暂停光阴：三潭印月中暂停或恢复水波和柳枝。
- 归于画境：恢复初始构图。
- 留一帧：保存不含按钮的 PNG 画面。
- 全屏：切换全屏欣赏。
- H：隐藏或显示界面。

场景尊重系统的减少动态效果设置。宽屏更适合欣赏完整构图。

## 文件

`catalog.js` 管理三十景名单与画境，`atlas.js` 为景目导航，`destinations.js` 管理按需载入，`painted-scene.js` 创建分层绘景，`three-pools.js` 保留原始混合三维场景。`main.js` 为场景与交互，`style.css` 为界面样式，`public/assets/` 包含本地模型及贴图。素材制作信息见 `ASSETS.md`。

运行中的本地服务可用 `npm test` 检查；该命令需要已安装的 `agent-browser`，可通过 `SCENE_URL` 指定其他地址。

完整三十景的切换、缓存释放、深链接和景目对话框检查：

```sh
SCENE_URL=http://127.0.0.1:5182/ node tests/thirty-scenes.mjs
```

早期实体模型源码保留在 `scripts/models/`；二十九景的在线画面改用 `public/assets/painted/` 下的独立绘景素材。

按景加载的网络回归检查：`SCENE_URL=http://127.0.0.1:5183/ node tests/loading.mjs`。检查首屏不请求其他景点、逐景绘画加载、三潭印月代码按需下载、缓存重访和切景取消旧图片请求。
